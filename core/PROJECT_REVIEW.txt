1. HTML TEMPLATES SUMMARY & QUICK REFERENCE
--------------------------------------------------------------------------------

[1] home.html
    - URL Path   : /
    - URL Name   : 'home'
    - View Func  : home()
    - Purpose    : Landing page with hero banner, quick search bar, and 
                   featured listings.

[2] teachers_list.html
    - URL Path   : /teachers/
    - URL Name   : 'teachers'
    - View Func  : teacher_list()
    - Purpose    : Dedicated directory displaying all registered tutors with 
                   verified badges, filtering, contact buttons, & actions.

[3] teacher_detail.html
    - URL Path   : /teacher/<id>/
    - URL Name   : 'teacher_detail'
    - View Func  : teacher_detail()
    - Purpose    : Detailed profile page for a single teacher (qualification, 
                   fees, full subject breakdown, location).

[4] add_teacher.html
    - URL Path   : /add_teacher/
    - URL Name   : 'add_teacher'
    - View Func  : add_teacher()
    - Purpose    : Form page allowing new teachers to register. 
                   (Saves to Database & updates teachers.xlsx).

[5] edit_teacher.html
    - URL Path   : /edit_teacher/<id>/
    - URL Name   : 'edit_teacher'
    - View Func  : edit_teacher()
    - Purpose    : Update existing teacher profiles (Requires phone verification).

[6] delete_confirm.html
    - URL Path   : /delete_teacher/<id>/
    - URL Name   : 'delete_teacher'
    - View Func  : delete_teacher()
    - Purpose    : Confirmation prompt before removing a teacher entry 
                   (Requires phone verification).

[7] messpg_list.html
    - URL Path   : /messpg/
    - URL Name   : 'messpg_list'
    - View Func  : messpg_list()
    - Purpose    : Directory of all available Mess & PG listings across districts.

[8] add_messpg.html
    - URL Path   : /add_messpg/
    - URL Name   : 'add_messpg'
    - View Func  : add_messpg()
    - Purpose    : Form page allowing PG/Mess owners to submit their property.

[9] mess_detail.html
    - URL Path   : /mess/<id>/
    - URL Name   : 'mess_details'
    - View Func  : mess_details()
    - Purpose    : View specific PG/Mess details & dynamically increment 
                   view count in database.
